# مشروع معرض أعمال Front-End — Ali

صفحة هبوط عربية تجريبية لخدمات تصميم وتطوير المواقع، مناسبة للتعلم والتعديل قبل إضافتها إلى معرض الأعمال.

## التقنيات
- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- JavaScript (قائمة الهاتف ورسالة نموذج التواصل)

## التشغيل
1. فك ضغط الملف.
2. افتح `index.html` في المتصفح.
3. عدّل النصوص والألوان والمحتوى ليناسب أسلوبك.

## ملاحظات مهمة
- بيانات الأرقام والمشروعات داخل الصفحة تجريبية وليست إحصاءات حقيقية.
- نموذج التواصل واجهة تجريبية فقط ولا يرسل بيانات إلى خادم.
- قبل عرضه في معرض أعمالك، عدّل المحتوى وأضف لقطات شاشة ورابطًا مباشرًا للموقع بعد نشره.
